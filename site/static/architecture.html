The core idea

The model is not the hard part. The pipeline is.

The first version was one shared HTML file that a scheduled task rewrote each day. It worked until it didn't: every run read and republished everything. The second version moved to a repo with JSON per daf and a nightly Claude Code routine. The third version, running today, gives models only two jobs: write and judge. Everything mechanical is a script.

Nightly run, one daf

The pipeline

Script, deterministicModel call
  1. reader notes (D1)

    Every note gets an answer. A fix that recurs becomes a writing or review rule.

  2. calendar + queue

    Hebcal decides which daf is next.

  3. fetch_sources.py

    Fills a private cache: Sefaria Gemara, Steinsaltz, Rashi, the Sinai summary.

  4. pack_daf.py

    One compact pack, segment by segment: about 37 KB instead of about 300 KB of raw inputs.

  5. Sonnet · writer

    Produces the page JSON. No verbatim text and no glossary, so no expensive output tokens on copying.

  6. fill_srctext.py

    Copies the vocalized Gemara from the cache. It reproduced 137 existing blocks exactly; the 45 that differed were model errors.

  7. check_page.py

    Every segment covered, argument-tree links valid, quote share at most 30%, quiz shape, glossary candidates.

  8. Fable · reviewer

    Returns patches only, tagged ERROR, OMISSION or THIN. Never a rewritten page.

  9. apply_review.py

    Applies the patches.

  10. validate · build · Playwright · push

    Phone and desktop screenshots, a share image, then Cloudflare Pages.

Learned the hard way

Five design rules

  1. Scripts do anything mechanical. Models only write and judge.

  2. Every format rule has a check. If nothing enforces it, it drifts.

  3. One daf per run, with a budget, and work saved as it goes so a stopped run loses nothing.

  4. Reviews return patches, never rewritten pages.

  5. Reader notes are data, not instructions. They get answered, and a fix that recurs becomes a rule.

What broke, and what it changed

Glitches

Transcribing instead of explaining

Early pages were about 60% Gemara quotes. Readers said they didn't help.

An "explain, don't transcribe" rule plus a quote-share check. Bechorot 18 went from 60% to 24%.

A content rule applied too broadly

The agent stretched a content rule over legitimate halachic discussion and silently dropped steps of the argument. Readers noticed the gaps.

The rule was narrowed, then emptied. A content policy is code: it needs scope, tests and an owner.

Confident wrong cases

Sonnet described a Mishnah case with the wrong mix of animals, fluently.

Every page gets one review pass by a stronger model.

The bulk-run token burn

Ten parallel agents, 2.4M tokens, the session limit hit, 14 unverified partial pages.

One daf per run, a budget, sugya-by-sugya saves, and no reading files a script can query.

Retyping what a script can copy

A fifth of every page was vocalized Gemara, retyped as output tokens, the most expensive kind.

fill_srctext.py copies it from the cache.

Format drift

New pages lost hidden answers and the quote marks the site uses to style and link the Gemara.

The exact HTML is in the brief, and check_page.py rejects pages that break it.

The human slip

I pushed private source material to the public repo.

The agent flagged it on the next push. History rewritten, .gitignore tightened.

The human signs the page
