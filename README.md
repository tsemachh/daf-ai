# daf-ai — דפי לימוד לדף היומי

Interactive Hebrew study pages for Daf Yomi, generated by an AI agent and verified against the Gemara text.
Content lives as JSON; a zero-dependency Python generator renders a static site.

## Layout

| Path | What |
|---|---|
| `data/<slug>/<daf>.json` | One daf: header, nav, storyline (הקדמה), sugyot with steps + argument tree, quiz, links, source texts |
| `data/glossary.json` | Shared glossary (sages, concepts). Longest key wins; first occurrence per page is marked |
| `data/sources.json` | Shared verse / halacha texts shown in the in-page source dialog |
| `content/home_about.html` | Static blocks on the home page |
| `site/app.css`, `site/app.js` | Shared runtime: glossary popovers, source dialogs, tree view, chavruta mode, settings, quiz |
| `build.py` | `data/` → `dist/` (`/`, `/<slug>/`, `/<slug>/<daf>/`) |
| `validate.py` | Schema + content checks; non-zero exit on errors |
| `tools/extract_from_hub.py` | One-time migration from the original single-file hub |

## Run locally

```bash
python validate.py        # must pass
python build.py           # writes dist/
python -m http.server -d dist 8000
```

## Daf JSON (summary)

```jsonc
{
  "key": "bechorot9", "tractate": "Bekhorot", "slug": "bechorot", "tractate_he": "בכורות", "daf": 9,
  "title": "בכורות ט׳", "eyebrow": "…", "thesis": "…", "meta": ["<hebrew date>", "עמודים א–ב", "~20 דקות לימוד"],
  "nav": [{"id": "s2", "amud": "עמוד א", "title": "…"}],
  "storyline": "<one paragraph, html allowed>",
  "sections": [
    {"id": "s2", "kind": "sugya", "ref": "Bekhorot.9a.7-13", "amud": "עמוד א · גמרא", "title": "…",
     "quote": {"text": "…", "cite": "…"} | null,
     "flow": "<בקצרה: 1–3 sentences>",
     "pre": "<html before the steps>", "post": "<html after: verdicts, think boxes>",
     "steps": [{"tag": "קושיה", "type": "q|a|c|", "hideable": true, "p": 0, "body": "<html>"}]},
    {"id": "sum", "kind": "raw", "amud": "סיכום", "title": "…", "html": "<table…>"}
  ],
  "quiz": [{"q": "…", "o": ["…","…","…"], "a": 1, "e": "…"}],   // exactly 8
  "links": [{"href": "…", "text": "…"}],
  "srctext": {"Bekhorot.9a.7-13": {"t": "בכורות ט׳ ע״א", "p": ["<verbatim segment>", "…"]}},
  "card": {"date": "…", "topics": "…", "stats_html": ["<span>…</span>"]}
}
```

`p` = index of the earlier step this step responds to (argument tree). Step types: `q` question, `a` answer, `c` conclusion, empty = statement.

## Deploy — Cloudflare Pages

1. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git → `tsemachh/daf-ai`.
2. Build command: `python build.py` · Build output directory: `dist` · Root: `/`.
3. Environment variable `PYTHON_VERSION=3.11`.
4. Custom domains → add your domain (DNS on Cloudflare → one click).

Every push to `main` rebuilds and deploys.
